# Power BI Retail & Sales Analytics Project

## Overview
This project was completed as part of a **Data Technician Bootcamp** and focuses on transforming retail and sales data into meaningful business insights using **Microsoft Power BI**. The project demonstrates the complete analytics workflow, from data preparation and transformation to interactive reporting and data-driven storytelling.

## Key Skills Demonstrated

### Data Preparation & Transformation
- Cleaning and transforming raw data using **Power Query**
- Handling missing, duplicate, and inconsistent data
- Creating data models and establishing relationships between tables
- Applying data type conversions and transformation techniques to improve data quality

### Data Analysis with DAX
- Creating **calculated columns** for custom business metrics
- Developing **DAX measures** to support dynamic calculations and KPI reporting
- Performing aggregations and trend analysis to uncover actionable insights
- Building calculations to support sales performance monitoring and business reporting

### Interactive Reporting
- Designing and developing **interactive Power BI reports and dashboards**
- Implementing **slicers** and **filters** to allow users to explore data dynamically
- Creating drill-through and cross-filtering experiences for deeper analysis
- Enhancing user experience through intuitive report navigation

## Visualizations Created
The report incorporates a range of visualizations to present retail and sales data effectively, including:

- **Bar Charts** for category and product comparisons
- **Line Charts** for sales trend analysis over time
- **Pie Charts** for contribution and share breakdowns
- **Map Visualizations** for regional sales performance
- KPI Cards and Summary Metrics dashboards
- Comparative and trend-based visual reports

## Data Storytelling
A key objective of this project was to use **data storytelling** to communicate insights clearly and effectively. The reports were designed to help stakeholders:

- Identify high-performing products and regions
- Monitor sales trends and seasonal patterns
- Compare sales performance across categories
- Discover opportunities for improvement and growth
- Support data-driven decision making through visual analysis

Through this project, I developed practical experience in:

## Project Outcome
The final Power BI solution delivers an interactive and user-friendly view of retail and sales performance. By combining data transformation, DAX calculations, filters, slicers, and a variety of visualizations, the report enables users to explore trends, monitor key metrics, and make informed business decisions.
